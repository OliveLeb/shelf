# Conventional commits

Tous les messages de commit suivent la spécification [Conventional Commits](https://www.conventionalcommits.org/)
et sont rédigés **en anglais**.

Format : `<type>(<scope optionnel>): <description>`

- Types courants : `feat`, `fix`, `docs`, `chore`, `refactor`, `test`, `ci`.
- La description est en anglais, en minuscules, sans point final.
  Exemple : `feat: implement invitation-only authentication and accounts`.
- Le corps du message et les footers (`Closes #12`, `Refs #7`) sont également en anglais.
- Le scope, s'il est présent, est un mot unique en anglais (`auth`, `agents`, `backend`…).
