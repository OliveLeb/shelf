# Triage labels

| Rôle canonique | Label GitHub | Signification |
| --- | --- | --- |
| needs-triage | needs-triage | À évaluer |
| needs-info | needs-info | Informations complémentaires nécessaires |
| ready-for-agent | ready-for-agent | Spécification prête pour implémentation par un agent |
| ready-for-human | ready-for-human | Implémentation humaine requise |
| wontfix | wontfix | Ne sera pas traité |

Utiliser ces correspondances lorsqu’un skill mentionne un rôle de triage.
