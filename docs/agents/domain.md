# Documentation de domaine

Shelf utilise un contexte de domaine unique pour le backend, le web et le mobile.

Avant d’explorer le code, lire `CONTEXT.md` à la racine et les ADR pertinents dans `docs/adr/`.
Si `CONTEXT-MAP.md` existe, suivre ses liens vers les contextes pertinents.
Si ces documents n’existent pas, continuer sans les créer par anticipation.

Employer le vocabulaire du glossaire dans les spécifications, issues et noms de tests.
Signaler toute contradiction avec un ADR existant avant de proposer un changement.
